# よるのたからさがし

## 遊び方
事前にアプリ内で表示されるQRコードを印刷しておいてください

<img width="524" height="566" alt="スクリーンショット 2026-09-20 23 43 17" src="https://github.com/user-attachments/assets/16aad0c1-d703-4fee-9bcf-0d6a4910aa7f" />

写真プリントで一括印刷して、段ボールなど厚紙に貼ると遊びやすいです
（例）
<img width="526" height="629" alt="image" src="https://github.com/user-attachments/assets/af1dcbd1-c32a-4cb0-9fd6-6af782585773" />


1. 「おとなのメニュー」を長押しし、あたらしいぼうけんで、今回かくす枚数（1〜5）を選ぶ

https://github.com/user-attachments/assets/7ae1d9be-a428-4b8e-8975-557771dd91a2

3. 「1まいめ」「2まいめ」…のカードをかくして、ヒントを書く

https://github.com/user-attachments/assets/a35de8ef-b019-42a0-9f30-32d1766a4ac6







3. 子どもに端末を渡してスタート。ヒントが読み上げられるので、それを手がかりに隠されたQRタグを見つけてカメラで読むと、次の隠し場所のヒントが表示されます


https://github.com/user-attachments/assets/c738f5a2-b7c6-4f89-9097-6a6070767bde




3. 最後のQRでたからばこが開き、たからをGET


https://github.com/user-attachments/assets/11d9eaa5-52bd-4be3-b081-38b2bf73a314
