# よるのたからさがし

子ども向けの段階式QR宝探し。**Swift / SwiftUI の iOSアプリ**です。iPhone と iPad のホーム画面に入れて遊びます。

カメラは AVFoundation、読み上げは AVSpeechSynthesizer、クリアの宝箱は SceneKit です。

QRは毎回印刷しません。**番号つきの5まい**をいちど用意して、ぼうけんごとに使う枚数とヒントだけ変えます。

## iOS端末に入れる

Mac と、入れる iPhone または iPad、無料の Apple ID が必要です。

```bash
open TakaraSagashi/TakaraSagashi.xcodeproj
```

1. iPad / iPhone をケーブルでつなぐ
2. Xcode 上のバーでその端末を選ぶ
3. **Signing & Capabilities** で Team に自分の Apple ID を選ぶ
4. 再生ボタン（▶）を押す
5. 「信頼されていないデベロッパ」と出たら、端末の **設定 → 一般 → VPNとデバイス管理** で信頼する

ホーム画面に「たからさがし」のアイコンがつきます。Safari は使いません。

無料の個人チームだと、だいたい7日ごとに入れ直しが必要です。

## 遊び方

1. アプリを開く
2. 「おとなのメニュー」を長押し（または5回タップ）
3. 「5まいのQRカードをみる」でカードを表示し、番号がわかるようにいちど印刷する
4. あたらしいぼうけんで、今回かくす枚数（1〜5）を選ぶ
5. 「1まいめ」「2まいめ」…のカードをかくして、ヒントを書く
6. 子どもに端末を渡してスタート
7. ヒントが読み上げられるので、QRをカメラで読む
8. 最後のQRで宝箱が開き、宝をGET
9. 「たからばこ」で集めた宝を見る

今回使わない番号のカードを読むと、「このぼうけんでは使わないカード」と伝わります。
