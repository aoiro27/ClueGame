# よるのたからさがし

子ども向けの段階式QR宝探し。**Swift / SwiftUI の iOSアプリ**です。iPhone と iPad のホーム画面に入れて遊びます。

カメラは AVFoundation、読み上げは AVSpeechSynthesizer、クリアの宝箱は SceneKit です。

QRは毎回印刷しません。**番号つきの5まい**をいちど用意して、ぼうけんごとに使う枚数とヒントだけ変えます。

## iOS端末に入れる

Mac と、入れる iPhone または iPad、無料の Apple ID が必要です。

```bash
open TakaraSagashi/TakaraSagashi.xcodeproj
```

1. iPad / iPhone をケーブルでつなぐ
2. Xcode 上のバーでその端末を選ぶ
3. **Signing & Capabilities** で Team に自分の Apple ID を選ぶ
4. 再生ボタン（▶）を押す
5. 「信頼されていないデベロッパ」と出たら、端末の **設定 → 一般 → VPNとデバイス管理** で信頼する

ホーム画面に「たからさがし」のアイコンがつきます。Safari は使いません。

無料の個人チームだと、だいたい7日ごとに入れ直しが必要です。

## 遊び方

1. アプリを開く
2. 「おとなのメニュー」を長押し（または5回タップ）
3. 「5まいのQRカードをみる」でカードを表示し、番号がわかるようにいちど印刷する
4. あたらしいぼうけんで、今回かくす枚数（1〜5）を選ぶ
5. 「1まいめ」「2まいめ」…のカードをかくして、ヒントを書く
6. 子どもに端末を渡してスタート
7. ヒントが読み上げられるので、QRをカメラで読む
8. 最後のQRで宝箱が開き、宝をGET
9. 「たからばこ」で集めた宝を見る

今回使わない番号のカードを読むと、「このぼうけんでは使わないカード」と伝わります。

## 演出用の音素材

配置先は `TakaraSagashi/TakaraSagashi/Audio/` です。フォルダ全体をXcodeのリソースに登録済みなので、下記の名前で配置して再ビルドするだけで反映されます。音源は同梱済みです。未配置でも画面演出・振動は動作し、該当音のみ無音になります。

| ファイル名 | 用途 | 推奨する内容・長さ |
| --- | --- | --- |
| `bgm_forest.mp3` | ホーム・準備・図鑑 | 夜の森のやさしい曲、30〜90秒、継ぎ目のないループ |
| `bgm_adventure.wav` | ヒント・QRカメラ・発見画面 | わくわくする探索曲、30〜90秒、継ぎ目のないループ |
| `bgm_victory.wav` | クリア画面 | 喜びの余韻の曲、30〜60秒、継ぎ目のないループ |
| `sfx_qr_success.mp3` | 正解QR発見 | きらめく上昇チャイム、1〜2秒 |
| `sfx_qr_retry.mp3` | 正解以外のQR | やさしい案内音、0.2〜0.5秒 |
| `sfx_chest_charge.mp3` | 最後のQR直後 | 魔力が集まる音、1.2秒 |
| `sfx_chest_open.mp3` | 1.2秒後の宝箱開封 | 開く音＋光が広がる音、1秒 |
| `sfx_treasure_get.mp3` | 2.2秒後のお宝登場 | 華やかな短いファンファーレ、1〜3秒 |

読み込み時の拡張子は上表の素材に合わせて指定しています。差し替え時は同じファイル名・拡張子を使用してください。44.1kHzまたは48kHz推奨。BGMはループ前後の無音を除き、効果音は冒頭の無音を除いてください。画像・動画素材は不要で、光・紙吹雪・星・宝箱の演出はコードで描画します。

BGMはフェードで切り替わり、読み上げ中は音量が下がります。おとなのメニューからBGMと効果音を個別に切り替えられ、設定は保存されます。バックグラウンド移行時は音を止め、マナーモードを尊重します。「視差効果を減らす」設定では新しい粒子演出と画面の拡大アニメーションを抑えます。
